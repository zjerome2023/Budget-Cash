# Budget Tracker

Full-stack expense tracking app with React, Express, and MongoDB.

## Status

Project bootstrap (Step 0). See `PLAN.md` and `BUILD_STEPS.md` for the full build plan.

## Quick start

```bash
# Server
cd server
cp .env.example .env   # fill in values before running the API
npm install

# Client
cd client
cp .env.example .env
npm install
npm run dev
```
